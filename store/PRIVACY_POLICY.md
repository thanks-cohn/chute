# Chute Privacy Policy

Last updated: August 21, 2026

Chute is a local file and image handoff tool. Its purpose is to let you intentionally move files, images, links, and selected text between webpages and a local Chute companion running on your own computer.

## Data Chute handles

Chute can handle the following data only when needed for its user-facing features:

- files that you explicitly send, drop, recall, attach, or drag through Chute;
- webpage images that you explicitly send or drag into Chute;
- links or page addresses that you explicitly send to Chute;
- text that you explicitly select and send to Chute;
- local Chute item metadata such as filename, MIME type, size, timestamp, and local item ID;
- Chute preferences such as browser access mode, history display count, thumbnail settings, drag mode, and image-capture settings.

## Where data goes

File contents, captured images, links, text, basket data, and history are sent to and stored by the local Chute companion on your computer through the loopback address `127.0.0.1:17891`.

Chute does not operate a remote Chute cloud storage service for this data. Chute does not sell user data, sell browsing activity, or send basket contents to advertising or data-broker services.

## Chrome Sync preferences

The extension uses `chrome.storage.sync` for small Chute preference values. If Chrome Sync is enabled in your browser, Chrome may synchronize those preference values using Google's Chrome Sync infrastructure. Chute does not place file contents, captured images, Chute history, or basket contents in Chrome Sync.

## Website access

Chute can run its browser drop interface on normal HTTP and HTTPS pages. Page access is used only to provide Chute's user-facing browser handoff features, including the sticky drop target, detecting user-initiated drag/drop operations, capturing an image the user explicitly sends, and attaching a Chute item to a user-selected webpage target.

Chute does not use page access to build advertising profiles, sell browsing histories, or collect browsing activity for unrelated purposes.

## Payments

If you purchase a Chute companion product, payment is handled by the disclosed payment provider or seller checkout. The Chrome extension does not store raw payment-card numbers in the local Chute basket.

## Retention and deletion

Local Chute files and history remain on your computer until they are removed according to Chute's local storage behavior. Clearing the live Chute basket does not necessarily erase recallable history or preserved local copies. Users can remove Chute's local data from their own computer.

## Sharing

Chute does not sell personal information. Chute does not transfer Chute basket contents to third parties for advertising, credit decisions, or data resale.

## Changes

If Chute's data-handling practices materially change, the disclosure and this policy should be updated before or alongside the product change.

## Contact

Use the publisher support/contact information shown on Chute's Chrome Web Store listing or project website.
