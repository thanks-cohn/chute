# Chrome Web Store listing — Chute

## Name

Chute

## Single purpose

Move user-chosen files, images, links, and selected text between webpages and one local Chute shared by the user's Chromium browsers.

## Short description

One local Chute shared across Chrome, Opera, Edge, Brave and other Chromium browsers.

## Detailed description

Chute is a local browser handoff workspace. Drop an image, file, link, or selected text into Chute, then pick it up again from the popup or Shelf and use it in another webpage or browser.

### One Chute, many browsers

Chute's basket belongs to the small local desktop companion, not to one browser profile. Install the extension in compatible Chromium browsers on the same computer and they all meet at the same Chute on `127.0.0.1:17891`.

### Fast desktop setup

If the local companion is not running, the extension detects the operating system and shows the matching setup. Windows users receive the Windows companion; Linux users receive the Linux companion. Once installed, the companion starts automatically for that user and the setup notice disappears.

### Image workflow

Chute can preserve the full browser image, create an optional custom-size WebP derivative, and generate tiny recognition thumbnails. Originals, custom copies, and menu thumbnails are stored separately.

### Recall and provenance

The live Chute can be cleared without deleting dated history. Browser-image captures can record the page URL, direct image URL, capture time, and local artifact locations so an image can be traced back later.

### Local-first

Files and captured content go to the Chute companion on your own computer. Chute does not require a Chute cloud account and does not use a remote Chute storage service for the basket.

### Features

- floating browser drop target
- right-click Send to Chute
- full-image capture
- configurable custom-size image copies
- generated visual thumbnails
- dated local history and Recall
- source/provenance records for browser image captures
- side-panel Shelf
- drag/attach the actual preserved file back into webpages
- one local Chute shared across compatible Chromium browsers

## Companion disclosure

Core basket/storage functionality requires the local Chute desktop companion. The extension clearly detects when it is missing and offers the matching desktop setup rather than transmitting files to a remote fallback service.
